# 钓鱼大师 🎣

一个纯前端的**第一人称钓鱼小游戏**，右上角住着一只 AI 氛围组橘猫「鱼蛋」——等鱼时陪你闲聊解闷，鱼咬钩时催你拉杆，钓上鱼时大喊"太棒了！"和你一起庆祝。

## ✨ 玩法

- **抛竿**：长按鼠标/空格蓄力，松开抛出，蓄力越满抛得越远
- **等鱼**：浮漂随波起伏，水下鱼影游动；鱼会先试探（浮漂轻颤），然后猛咬钩
- **咬钩**：红色警报闪烁，限时约 1 秒内拉杆，手慢饵就没了
- **遛鱼**：按住收线，张力指针保持在绿色安全区——进红区断线，太松脱钩；鱼会周期性猛冲，要学会"放线"，鱼累了就好拉了
- **收获**：大鱼跃出水面，弹出渔获卡片；7 种鱼（小鲫鱼到传说黄金鲤）+ 破靴子等搞笑"空军"事件
- 游戏内昼夜循环（4 分钟一天），**黄昏和夜晚稀有鱼概率大增**
- 图鉴收集、最大鱼纪录、合成音效（水花/警报/庆祝小号），localStorage 自动存档

## 🐱 氛围组宠物「鱼蛋」

- 等待时每 20~40 秒闲聊打气，还会根据**等了多久**吐槽"空军"
- 咬钩/遛鱼等快速事件用零延迟的本地台词；等待闲聊和钓获庆祝走大模型，会结合**当前时段（黄昏/夜晚）、鱼的品种重量稀有度、是否新纪录、累计渔获**即兴发挥，很有梗
- 内置浏览器**语音朗读**（Web Speech API），橘猫人设高音调，可在设置里开关
- 戳一戳猫头和它互动

## 🤖 接入大模型

点右上角 ⚙️ 打开设置，勾选"AI 氛围组"，填入任意 **OpenAI 兼容接口**（`/chat/completions`）：

| 项 | 说明 |
|---|---|
| Base URL | 如 `http://localhost:1234/v1`（LM Studio） |
| API Key | LM Studio 可随便填 |
| 模型 | 已加载的模型 ID |
| 关闭思考模式 | **本地推理模型（Qwen3 / DeepSeek-R1 等）必须勾选**，否则思考过程会吃光输出额度导致回复为空 |

提供"测试连接"按钮；未配置或调用失败时自动回退到内置台词库，永远不会冷场。气泡右下角标注来源：🤖AI = 大模型生成，📻 = 本地台词。

## 🚀 运行

```bash
npm install
npm run dev        # 开发模式
```

## 📦 构建

```bash
npm run build          # 普通构建
npm run build:static   # 纯静态版：dist/ 下只有 index.html + app.js + app.css
```

`build:static` 产物是经典 IIFE 脚本（非 ES Module）+ 相对路径，**双击 `dist/index.html` 即可离线游玩**，不需要任何服务端，整个 `dist` 文件夹拷走就能跑。

## 🛠️ 技术栈

React 19 + TypeScript + Vite + Tailwind CSS + Canvas 2D（自研游戏引擎，无游戏框架）

- `src/game/engine.ts` — 游戏状态机与渲染（抛竿/等待/咬钩/遛鱼/起鱼）
- `src/pet/companion.ts` — 宠物大脑：本地台词库 + 大模型接入
- `src/pet/voice.ts` — 浏览器语音朗读
- `scripts/make-static.mjs` — 静态化后处理（IIFE 构建的 CSS 抽离）
