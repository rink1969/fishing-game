# 钓鱼大师 🎣

> [!WARNING]
> **重要提醒**：本项目完全由AI开发，目的是测试 Coding Agent 能力。请勿提交改进游戏的issue！也不要将游戏用于商业场景！！！游戏中的素材均来自网络，可能存在版权方面的问题。

一个纯前端的**第一人称钓鱼小游戏**（寻霖塘国风主题）。右下角住着一只 AI 氛围组小象「鱼蛋」——等鱼时陪你闲聊解闷，鱼咬钩时催你拉杆，钓上鱼时大喊"太棒了！"和你一起庆祝。

## ✨ 玩法

- **抛竿**：长按鼠标/空格蓄力，松开抛出，蓄力越满抛得越远
- **等鱼**：浮漂随波起伏，水下鱼影游动；鱼会先试探（浮漂轻颤），然后猛咬钩
- **咬钩**：红色警报闪烁，限时拉杆，手慢饵就没了
- **遛鱼**：按住收线，张力指针保持在绿色安全区——进红区断线，太松脱钩；大鱼会周期性猛冲，要学会"放线"，鱼累了就好拉了
- **收获**：大鱼跃出水面，弹出渔获卡片；56 种鱼（按 6 档稀有度区分战力与价值）+ 破靴子等搞笑杂物
- **经济系统**：卖鱼赚灵玉 → 买更好的鱼饵、解锁新钓点；11 个国风钓点各有专属背景图与鱼群分布
- **回家结算**：随时收竿回家，查看本次渔获/鱼饵消耗/灵玉结算（含未出售渔获估值），可选择重新开始

## 🐘 氛围组宠物「鱼蛋」

- 等待时每隔一段时间闲聊打气，说话简短有梗
- 咬钩/遛鱼等快速事件用零延迟的本地台词（AI 来不及反应）；等待闲聊、钓获庆祝和回家总结走大模型，会结合**钓点、鱼的品种重量稀有度、是否新纪录**即兴发挥
- 内置浏览器**语音朗读**（Web Speech API），可在设置里开关
- 8 种姿态表情（招手/读书/喝茶/扫地/睡觉/害羞/跳跃/庆祝），戳一戳它会跟你互动

## 🎵 音乐与音效

- 背景音乐《A Kettle on the Hearth》循环播放，默认开启，可在设置里关闭
- 合成音效（水花/警报/庆祝小号），可一键静音
- 鱼蛋语音朗读默认关闭，需要时在设置里打开

## 🤖 接入大模型

点右侧 ⚙️ 设置，勾选"AI 氛围组"，填入任意 **OpenAI 兼容接口**（`/chat/completions`）：

| 项 | 说明 |
|---|---|
| Base URL | 如 `http://localhost:1234/v1`（LM Studio） |
| API Key | LM Studio 可随便填 |
| 模型 | 已加载的模型 ID |
| 关闭思考模式 | **本地推理模型（Qwen3 / DeepSeek-R1 等）必须勾选**，否则思考过程会吃光输出额度导致回复为空 |

提供"测试连接"按钮；未配置或调用失败时自动回退到内置台词库，永远不会冷场。气泡右下角标注来源：🤖AI = 大模型生成，📻 = 本地台词。

## 🚀 运行

```bash
npm install
npm run dev        # 开发模式
```

## 📦 构建

```bash
npm run build          # 普通构建
npm run build:static   # 纯静态版：dist/ 下只有 index.html + app.js + app.css
```

`build:static` 产物是经典 IIFE 脚本（非 ES Module）+ 相对路径，**双击 `dist/index.html` 即可离线游玩**，不需要任何服务端，整个 `dist` 文件夹拷走就能跑。

## 🌐 在线版（GitHub Pages）

仓库已配置 GitHub Actions（`.github/workflows/deploy.yml`）：push 到 `main` 自动构建并部署到 GitHub Pages。
首次使用需在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**。

线上地址：https://rink1969.github.io/fishing-game/

> 提示：线上版是 HTTPS，连本地 LM Studio（`http://localhost:1234`）可能被浏览器混合内容策略拦截；本地双击 `dist/index.html` 没有此限制。
